# Weekly Programming 26-31

## Demo 下的 HTML 与 HTMX

在需要向用户展示可交互页面的情况下, 可以使用 AI 快速生成一个可运行的 Demo 文件, 让用户自己进行体验

Demo 文件的编程语言, 可选项为 HTML 和 HTMX

使用 AI 分别用 HTML 和 HTMX 编写一个同样的静态的 Demo 文件, 会有什么样的不同

先说结论: 目前来看, 在需要编写 Demo 的情况下, HTMX 没有任何优势

### 语法

* 在编写 HTML 文件的过程中, 基本不会出现任何错误, 将可交互的内容以及样式描述清楚后, 可以一次性生成完整的 HTML 文件
* HTMX 文件有时则会出现错误, 无法打开, 功能不全或无法交互

### 运行

* HTML 文件可直接通过浏览器运行, 不需要其他任何开发环境运行时
* HTMX 文件则需要启动服务, 对用户来说可能无法打开
